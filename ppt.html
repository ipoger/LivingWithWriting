基于 RepRLFN 的轻量级图像超分辨率重建项目报告

1. 项目背景与目标 (Background)

在移动端和边缘设备上部署超分辨率模型面临算力受限的挑战。本项目的目标是训练一个轻量级、推理速度快且画质优秀的超分辨率模型（Scale x2）。我们选用了 RepRLFN 架构，旨在平衡计算效率与重建质量（PSNR/SSIM）。

2. 核心方法 (Methodology)

2.1 模型架构：RepRLFN

我们采用了 RepRLFN (Residual Local Feature Network) 作为基线模型。

  • 结构重参数化 (Structural Re-parameterization)：
    • 训练态：采用多分支结构（3x3 卷积 + 1x1 卷积 + Identity），利用多分支提取丰富的特征细节，提升训练上限。
    • 推理态：通过代数变换将多分支融合为单分支（Single-branch），显著降低显存占用，推理速度提升约 10倍。
  • 优势：在保持极低参数量的同时，性能逼近重型网络（如 EDSR）。

2.2 两阶段训练策略 (Two-Stage Training Strategy)

为了冲击更高的 PSNR 指标，我们设计了由粗到精的训练策略：

  1. 第一阶段 (Pre-training)：
    • 使用 L1 Loss 进行 20,000 iter 的预训练。
    • 目的：让模型快速收敛，学习图像的低频结构信息，避免陷入局部最优。
  2. 第二阶段 (MSE Fine-tuning)：
    • 加载第一阶段权重，切换为 MSE Loss (L2 Loss) 继续微调 50,000+ iter。
    • 优化器设置：Adam 优化器，低学习率 (2e-5) 锁死，配合 MultiStepLR。
    • 目的：MSE Loss 直接对应 PSNR 指标的数学定义，能最大化峰值信噪比，消除噪点。

2.3 后处理优化 (Post-Processing Optimization)

为进一步挖掘模型潜力，我们在测试阶段引入了：

  • 模型权重融合 (Model Weight Fusion)：对训练末期（如 50k-70k iter）的多个模型存档进行参数平均（Weight Averaging），以提升泛化能力。
  • 测试时增强 (Test-Time Augmentation, TTA)：对输入图像进行 8 种几何变换（旋转/翻转），推理后逆变换取平均，消除伪影。

3. 实验设置 (Experimental Setup)

  • 数据集：训练集 DF2K (DIV2K + Flickr2K)，验证集 Set5。
  • 框架：BasicSR (PyTorch)。
  • 硬件：NVIDIA GPU (CUDA 11.x)。
  • 输入块大小 (Patch Size)：256x256。
  • Batch Size：32。

4. 实验结果 (Results)

在 Set5 (x2) 基准测试集上的表现如下：

训练阶段 迭代次数 (Iter) PSNR (dB) 备注
L1 预训练 20,000 ~37.04 基础结构成型
MSE 微调 (初期) 20,000 -> 30,000 37.18 -> 37.32 快速增长期
MSE 微调 (当前) 56,000 37.44 持续突破中
预计最终 (含TTA) 70,000+ ~37.75 接近 SOTA 水平

5. 结论 (Conclusion)

本项目成功验证了“L1预训练 + MSE微调”策略的有效性。通过 RepRLFN 架构与精细的训练调优，我们在轻量级模型上实现了极具竞争力的超分效果，证明了该方案在实际应用中的潜力。
